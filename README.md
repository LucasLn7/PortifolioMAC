#  Lucas Lima — Portfólio Interativo

Um portfólio pessoal desenvolvido para apresentar minha trajetória na área de Tecnologia da Informação, meus conhecimentos técnicos, experiências e projetos de desenvolvimento.

A proposta é transformar a navegação tradicional de um portfólio em uma experiência interativa, simulando um sistema operacional desktop, com janelas, animações, terminal e funcionalidades que permitem explorar cada seção de maneira dinâmica.

##  Demonstração

**Acesse o portfólio:** [Visualizar projeto](https://lucasln7.github.io/lucas-portfolio/)

## Funcionalidades

- **Desktop interativo:** interface inspirada no macOS, com janelas que podem ser abertas, fechadas, minimizadas, maximizadas e movimentadas.
- **Tela de inicialização:** animação de boot e tela de login personalizada.
- **Sobre mim:** apresentação pessoal, formação acadêmica e trajetória profissional.
- **Experiência profissional:** informações sobre minha atuação como estagiário de TI — Help Desk.
- **Skills:** apresentação das tecnologias e ferramentas que fazem parte dos meus conhecimentos.
- **Projetos:** exposição dos projetos desenvolvidos, com acesso aos repositórios e demonstrações.
- **Terminal interativo:** permite executar comandos como `help`, `whoami`, `skills`, `projetos` e `clear`.
- **Busca Spotlight:** pesquisa rápida de funcionalidades e seções utilizando `Ctrl + K`.
- **Integração com GitHub API:** consulta dinâmica de informações do perfil e repositórios públicos.
- **Assistente virtual Paimon:** guia interativa que auxilia os visitantes a navegar pelo portfólio e conhecer minhas experiências.
- **Integração com WhatsApp:** formulário de contato que direciona mensagens diretamente para o WhatsApp.
- **Spotify:** espaço para incorporar uma playlist pessoal.
- **Currículo:** visualização do currículo em PDF.
- **Responsividade:** adaptação da interface para dispositivos móveis.

##  Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Estilização, animações e responsividade |
| JavaScript | Interatividade e funcionalidades |
| Git e GitHub | Versionamento e hospedagem |
| GitHub REST API | Consulta de perfil e repositórios |
| Font Awesome | Ícones da interface |
| Google Fonts | Tipografia personalizada |
| Spotify Embed | Incorporação de playlist |

**Observação:** o projeto foi desenvolvido utilizando HTML, CSS e JavaScript puros, sem frameworks ou bibliotecas JavaScript de interface.

## ⚙️ Como executar o projeto

1. Faça o clone do repositório:

```bash
git clone https://github.com/LucasLn7/lucas-portfolio.git
```

2. Entre na pasta do projeto:

```bash
cd lucas-portfolio
```

3. Abra o projeto no Visual Studio Code.

4. Execute o arquivo `index.html` utilizando a extensão **Live Server**.

5. Acesse o endereço local disponibilizado pelo Live Server.

## 🔧 Personalização

Algumas funcionalidades podem ser personalizadas diretamente no código:

- **GitHub:** altere o usuário utilizado nas requisições da API no arquivo `js.js`.
- **WhatsApp:** configure o número de telefone utilizado no formulário de contato.
- **Spotify:** adicione o link da sua playlist na variável `SPOTIFY_PLAYLIST`.
- **Conteúdo:** atualize suas informações pessoais, experiências, habilidades e projetos no `index.html`.

## Objetivo do projeto

Desenvolver um portfólio que fosse além de uma apresentação profissional convencional, explorando conceitos de desenvolvimento web, manipulação do DOM, eventos JavaScript, consumo de APIs, responsividade e experiência do usuário.

Também foi uma oportunidade de colocar em prática meus conhecimentos e experimentar novas possibilidades de interação utilizando tecnologias web.
